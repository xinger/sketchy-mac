## Sketchy 1.2.3

- Added image paste and drag-and-drop support, making it easier to bring visual references directly onto the canvas.
- Improved pasted image previews and placement behavior.
- Added clearer edge cues for opening drawing history and starting a new drawing.
- Made edge cues feel calmer and more responsive by fading them based on pointer proximity.
- Made the history sidebar easier to open with a left-edge click and less likely to close unexpectedly.
- Improved multi-window behavior: new windows now start with a blank drawing, and drawing history stays in sync across windows.
- Moved the pin control into the window chrome and aligned it with the native window controls.
- Rounded and lowered the bottom toolbar for a cleaner canvas layout.
- Refined freehand drawing so fast strokes preserve more input detail and curve peaks.
- Updated keyboard shortcuts for creating drawings and opening new windows.
- Refreshed the color palette with a purple final swatch.
