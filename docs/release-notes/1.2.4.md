## Sketchy 1.2.4

- Added Undo and Redo for drawing changes.
- Added `Cmd+Z` and `Cmd+Shift+Z` shortcuts, with matching Edit menu actions.
- Kept the last 50 drawing steps available for history navigation.
- Supported undo and redo for completed strokes and inserted images.
- Cleared redo history after making a new drawing change.
- Reset undo history when starting a new drawing or switching to another saved drawing.
- Improved autosave behavior so undoing the only change in a new unsaved drawing does not save stale content.
