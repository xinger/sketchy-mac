A quiet canvas for quick visual thinking.

Sketchy opens as a lightweight macOS app with a compact toolbar, drawing history, brush sizes, dashed strokes, and a pin mode when the canvas should stay above other windows.

first launch

Unsigned build, simple install.

Open the download, drag Sketchy.app to Applications, then remove quarantine if macOS blocks the first launch.

xattr -dr com.apple.quarantine "/Applications/Sketchy.app"

The DMG also includes Launch.command for this step. After that, Sketchy checks the signed Sparkle appcast for updates.
